The factory scorecard's red-train rate now counts each train (one batch of PRs tested together) once per report, by its branch, so re-testing the same batch inside the report's window no longer moves the rate. It used to divide red runs by every non-cancelled run on a train branch, so a red batch that was bisected and rebuilt added extra runs to the count. A train is now red when any of its non-cancelled runs in the window did not succeed, even if a later rebuild passed, and a branch whose runs were all cancelled is left out. A rebuild that lands after the window closes still counts in the next report. The published week in `crew/docs/recommended-harness.md` recounts the same (1 red of 22 trains).
